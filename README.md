# InkLook

A sumi-ink look and a live wet-ink canvas for Unity 6 URP.

**Site and docs:** https://saigouumi.github.io/inklook/

InkLook makes a whole game look painted in ink on paper: three flat ink tones, brushy outlines, wash, paper grain, world brush strokes and a painted scene transition. It also has a canvas where the ink is simulated, so it bleeds into the paper and dries with a dark rim. Use the canvas for painting, or as game effects: ink thrown at the screen, splashes on floors and walls, and recorded strokes that paint themselves.

This repo holds the website and the docs. The package itself is coming to the Unity Asset Store.

## Needs

- Unity 6 (6000.0 or newer)
- URP 17 (Built-in and HDRP are not supported)
